# 讓模型配置自己的 MCP

在本專案目錄開啟 Codex 或 Claude Code，把以下提示交給模型。模型應設定它自己正在使用的客戶端；雙方各執行一次，即可各自取得橋接工具。

```text
請把這個專案的 C-C 聊天橋接配置到你自己目前使用的 MCP 客戶端，讓你能透過對方的原生跨聊天介面列出、讀取聊天及互傳訊息。

先讀 README.md、docs/usage.md 與 examples/中對應你客戶端的範例，確認專案路徑、Node.js，以及有效的 Codex owner 聊天 ID 和當次原生管道。已有設定或接線資料就沿用並核對，不猜 ID 或管道；缺少你無法自行取得的值時，只詢問必要資訊。

將範例改成實際值後，合併到你自己客戶端適用的 MCP 設定，保留其他既有設定。使用絕對路徑，依文件設定工具逾時；個人接線資料留在本機，不提交到倉庫。不要替另一個客戶端修改設定。

用你實際的 MCP 連線列出橋接工具，並讀取 Codex、Claude 的聊天列表，確認雙方都可讀。若需要使用者重載客戶端，交代具體操作；不要把只寫好設定當作已連通。若要傳訊驗證，先取得使用者對目的聊天與測試內容的授權，並按文件區分派送、收到回覆與未知結果。

最後簡短回報設定位置、已確認能使用的功能，以及尚未連通的原因。
```

Codex 通常能從目前 Desktop 聊天取得 owner 與管道；Claude 若沒有這些值，可以請使用者在已授權的 Codex 聊天依 [使用說明](usage.md#取得-codex-來源與管道)取得。提示本身不包含任何人的私人接線資料。
